# Ajiro Agent v1.1.5

A major update focused on **conversation context management, chat UX improvements, and a more reliable Android release pipeline**.

## ✨ What's New

### Context Usage Indicator

* Added a context usage indicator with a circular progress ring.
* Added detailed token usage information for conversations.
* Added utilities for calculating context usage and formatting token counts.
* Added a dedicated context usage drawer for inspecting conversation context.

### 🧠 Conversation Compaction

* Added conversation compaction to summarize chat history and free up context tokens.
* Added compacting states for idle, working, completed, and failed operations.
* Compaction results and errors are now surfaced directly in the UI.
* Persisted system-role compaction messages are used by the context pipeline without being rendered as normal chat bubbles.

### 💬 Chat Experience Improvements

* Updated the empty chat experience with a more prominent welcome state and starter prompts.
* Improved navigation behavior so returning from sidebar screens restores the sidebar state.
* Added improved tool-approval messaging and clearer descriptions.
* Updated composer and UI behavior for a cleaner ChatGPT-style experience.
* Improved light and dark theme tokens.

### 🧩 Data & Internal Improvements

* Updated database migrations to include `agent_id` where required.
* Added new hooks and components for context and sidebar state management.
* Added and expanded unit tests around context usage and related functionality.

## 🔧 Release & Build Improvements

* Updated the application version to **1.1.5**.
* Updated Expo SDK 57 dependencies to their required compatible versions.
* Added `@types/node` for Node.js-based test utilities.
* Updated Android adaptive icon assets.
* Updated splash-screen configuration.
* Added a `preview` APK build profile alongside `production`.
* Updated the GitHub/EAS build environment to **Node.js 22.23.1** for improved compatibility.
* Continued the npm-based dependency workflow.
